# CS-WebUI 2.5.0-beta.4.11

Released 2026-11-26.

Adopts the official WebUI nightly
[`8a55352c2d7b6c0be9a149af417373714a390cb8`](https://github.com/webui-dev/webui/commit/8a55352c2d7b6c0be9a149af417373714a390cb8),
which adds one upstream fix to the previous pin `24c7d196e`. The WebUI header
and exports are unchanged, and CS-WebUI's API is unchanged.

## Index redirects keep the query string

WebUI's page server redirects `/` and folder URLs to their index file. It
dropped the query string on that redirect, so a page opened at `/?mode=x`
arrived at `index.html` without `?mode=x`
([#33](https://github.com/Runic-Artifex/cs-webui/issues/33)). WebUI now keeps
the query on the redirect
([webui-dev/webui#729](https://github.com/webui-dev/webui/pull/729)), with a
`SetFileHandler` handler as well as with `SetRootFolder`. A query longer than
8 KiB gets `414 URI Too Long` instead of a redirect. The file handler still
receives the path without the query.

## Tests

`WebUiIndexRedirectTests` requests `/?a=1&b=2` and `/docs/?a=1&b=2` with a
file handler and with a root folder, and checks that the redirect keeps the
query and that its target is served. Both tests fail against WebUI `24c7d196e`.
