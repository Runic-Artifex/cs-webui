# CS-WebUI 2.5.0-beta.4.7

The `osx-x64` and `osx-arm64` native libraries now load on macOS 15, the oldest
macOS supported by .NET 10. The official WebUI macOS archives used by beta.4.4
to beta.4.6 record `LC_BUILD_VERSION minos 26.0`. Release packages now contain
macOS libraries built by CS-WebUI CI from the same official upstream commit
`f1b28eeeecfc2d63bdb4d4857c6f137468c6d6f6`, using upstream's `GNUmakefile`
release recipe with a macOS 15.0 deployment target. Windows and Linux libraries
remain the verified official archives. The C header and its 112 exports are
unchanged.

Packaging fails if any shipped macOS Mach-O slice records a minimum macOS above
15.0. The macOS source-build digests and workflow run are recorded in
`provenance/WebUI/webui-macos-source-build.json` inside `CsWebUi.Native`. The
arm64 source-build and package smoke jobs now run on `macos-15`.

Prepared packages: `CsWebUi` and `CsWebUi.Native`, both
`2.5.0-beta.4.7`. Expected tag: `v2.5.0-beta.4.7`.

Publication remains pending successful exact-commit managed, Nix, NativeAOT,
package and five-platform native/consumer checks, followed by explicit
publication authorization. Attach the verified originals and provenance to
the versioned release as described in `RELEASING.md`.
