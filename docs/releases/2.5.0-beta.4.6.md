# CS-WebUI 2.5.0-beta.4.6

Native UTF-8 buffers now explicitly include their terminating zero byte,
including empty, Unicode and large-buffer values. This prevents stray trailing
bytes in native callback responses.

Official WebUI 2.5.0-beta.4 assets are refreshed to upstream commit
`f1b28eeeecfc2d63bdb4d4857c6f137468c6d6f6`. The C header and its 112 exports
remain unchanged. Verified original archives and upstream release metadata are
retained separately from package inputs. Source-build lifecycle verification
now runs the maintained native/server tests.

Prepared packages: `CsWebUi` and `CsWebUi.Native`, both
`2.5.0-beta.4.6`. Expected tag: `v2.5.0-beta.4.6`.

Publication remains pending successful exact-commit managed, Nix, NativeAOT,
package and five-platform native/consumer checks, followed by explicit
publication authorization. Attach the verified originals and provenance to
the versioned release as described in `RELEASING.md`.
